# HVAC 設計助手

本專案建立可覆核的 HVAC 設計流程：建築資料確認 → 公司設計標準 → 工程計算 → 系統與設備設計 → 固定格式成果。

## 狀態

2026-09-07：建立私有版本庫與前期基準文件。現階段完成需求登錄及來源盤點，尚未移植、修復或驗證舊計算核心；本倉庫未提供可執行的設計引擎。

## 已確認決策

- 首期：一般辦公／商業樓層空調通風，供內部工程設計覆核。
- 新風標準：10 L/s／人。
- 安全係數：1.15，只套用於最終冷負荷一次；新風維持 10 L/s／人，不額外放大新排風量。
- 修復並驗證既有逐時計算方法，不稱作真正 Carrier HAP 運算。
- 先統一公司設計標準，由用戶本人核准。
- FOP 威尼斯人 v1.1 為文件格式及內容深度的對照母本。
- 慕拉士 2023-11-18 原始冷量計算已獲用戶確認為核准基準，使用前仍須對齊房間、圖紙及工況。
- CLTD/SCL 出處不列為用戶前期必交資料；對外成果不要求特別標註。內部保留實際計算方法、資料版本與驗證狀態。

## 版本管理

`main` 保存已整理的專案基準；功能分支使用 `codex/` 前綴。原始大型工程文件保留在 Drive，Git 保存檔案 ID、內容雜湊及來源版本。現有 `hvac-workspace` 與 `hvac-design-assistant` 倉庫僅作參考，經核查後才逐項引入。
