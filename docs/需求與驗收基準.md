# 需求與驗收基準

日期：2026-09-07。階段：需求已確認；公司標準及計算實作待完成。

## 目標

使用 CAD／PDF 建築平面圖、項目要求、已蒸餾設計與計算資料及設備資料庫，完成 HVAC 設計，輸出固定格式設計說明、設計資料表與設備表，供內部工程師覆核。

首期為一般辦公／商業樓層空調通風。讀圖與空間資料整理屬設計前置；自動製圖、路由、造價及平台優化不屬本期。

## 固定成果

1. 設計條件及來源表。
2. 建築參數、通風計算及冷負荷三張主表，沿用既有 SOP 與 FOP 母本的閱讀結構。
3. 逐時分項、顯潛熱、房間與系統峰值的可追溯附錄。
4. 系統服務關係、設備性能需求、選用性能及工況比較的設備表。
5. 七章式設計說明 Word，與計算資料使用同一版本；2026-09-08 用戶確認不再交付 PDF。
6. 未決事項及獨立覆核紀錄。

## 驗收

- 原圖、房間、人數、面積及工況先確認，再進入正式計算。
- 同一輸入與版本須重現相同結果。
- 與核准計算比較前，建立空間、系統、單位與設計條件對應；不得只比較總冷量。
- 模組容許差異按方法、取整及基準資料事先制定，不自行宣稱固定百分比等效 HAP。
- 分項負荷、峰值時間、顯潛熱分工及風量平衡可覆核；系統彙總按同一時刻計算。
- 裕量不得重複套用。設備須按真實工況與性能比較，不採用已發現錯配的歷史風量門檻。
- Excel 必須實際重算；僅有公式字串或格式測試通過不代表工程正確。
- Word、主表、附錄與設備表的編號、數值與版本一致。
- 缺失資料不轉成零，未核事項不預填「符合」。

## 前期順序

1. 保存需求、來源及基準版本。
2. 提交公司標準完整建議表，集中解決未決參數，由用戶核准。
3. 以原始 HAP 報表及圖紙建立逐房對應，驗證並修復現有程式。
4. 完成單樓層設計試點及固定成果，再作獨立工程覆核。
