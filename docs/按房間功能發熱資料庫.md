# 按房間功能發熱資料庫

2026-09-07：用戶確認發熱備用值按房間功能整理。首版存於 `data/reference/internal_gains_by_function.json`，包含8類用途映射及12筆帶表號的數值參考。這是新設計助手的版本化資料，不是 Retool 材料庫的即時更新。

來源：[ASHRAE 2025 Fundamentals SI 第18章](https://handbook.ashrae.org/Handbooks/F25/SI/F25_Ch18/f25_ch18_si.aspx)。人員依 Table 4、照明依 Table 5、辦公設備依 Table 14 登錄。會議與培訓的人員活動映射屬本專案候選，須核對實際活動。

數值與適用條件保存在同一記錄。來源核對完成不代表已適用於所有工程：23°C的人員顯潛熱分配、照明裝機及設備配置仍須對應實際項目。已撤銷通用75／60 W、人均以外固定照明15及設備25 W/m²的提案。

設計流程先查實際資料；缺項時按用途列出候選及依據，由設計覆核選用並記錄假設。查無匹配資料顯示缺項，不補零。來源基準溫度、面積範圍或工作站密度不匹配時，不直接套入核心。特殊房間保留設備清單入口，逐項補充來源，不套辦公室密度。

每次選用需輸出房間ID、用途、參考ID、採用值與單位、項目條件、逐時排程、選用理由及覆核狀態。人員、照明與設備分開記錄，最終冷負荷才套一次1.15。現有核心仍接受顯式輸入；本版未增加自動選值或動態蓄熱模型。
