# 設備選型指引

## 狀態與證據

資料庫的 Confirmed 是資料覆核狀態，並非本工程的性能合格證明。Flagged 不自動採用；PendingReview、工況、來源或關鍵性能欠缺時只列有條件候選。原廠文件與資料庫名稱有矛盾時，設計端隔離該記錄，不假設型號為別名，不回寫原庫。

每次唯讀查詢保存不可覆寫的時間戳快照，設計資料包記錄原查詢日期、來源、檔案及 SHA-256。連線失敗只可使用明示日期的既有快照。原廠補查資料另存專案來源記錄。

## 兩階段選型

1. **配置初選**：先按用途、房間、系統形式、名義容量與風量篩選，再整理一個暫定方案及最多兩個有差異的備選。名義初選不等於設計點性能通過。
2. **性能核對**：以同一工況、同一轉速及可追溯性能核對。工況不符不自行修正；有原廠支持才可修正或插值。未通過時保留候選，不能改寫成已選定設備。

| 類型 | 必核內容 |
|---|---|
| DX／VRF | 逐房總冷量、顯熱、潛熱、送風量、最低調節能力；室外機容量與修正、精確配對、連接率、接機數、管長及高差。 |
| FCU | 進風與進出水工況、總冷量、顯熱、風量、ESP、水量、水阻；每項性能須屬相同選定運行點。 |
| 新風處理機 | 獨立 equipment_type=fresh_air_unit；進出風乾濕球、冷卻除濕、凝結水、再熱、風量、ESP、冷源配置；不可使用一般FCU容量代替。 |
| 風機 | 同一轉速的風量／靜壓工作點、密度、轉速、功率、控制及噪音。不得拼接最大風量與最大靜壓。 |

合格配置按容量匹配、可比的最低調節能力、台數及安裝維修条件比較。效率及噪音須工況可比才參與排序；單價未知不排序，原庫價格保持 NULL。

## 本次零售工程的初選政策

房間末端採壁掛 VRF 候選，按每房最多3台的安裝情境初選。送風12°C、室內23°C、密度1.2kg/m³及比熱1.006kJ/(kg·K)，用顯熱需求計算送風量：

`風量(L/s)＝顯熱(kW)×1000÷[密度(kg/m³)×比熱(kJ/kg·K)×溫差(K)]`

名義總冷量及名義高風速風量均須滿足初選情境。這只排除明顯不足，不能據此宣稱在23°C／55%RH下總冷量、顯熱或除濕性能已通過。接近的容量差在設計需求10%內視作同一匹配級，再比較台數；此為本工程配置政策，並非ASHRAE要求。小房間仍須核對最低調節能力，避免過大機組短循環。

排風75Pa、新風150Pa僅是路由前的阻力情境，未經路由計算，不列為已確定的選定靜壓。新風設計採中性送風，盤管冷卻除濕後再熱至23°C／55%RH，原室內末端負荷不扣減或重複加入新風負荷。原始冷負荷各施加一次1.15；新排風量不加冷負荷SF。

## 集中覆核

助手完成資料庫查詢、原型錄追查、名義配置比較及性能缺項整理。向使用者集中確認會改變方案的冷源／新風供應邊界及設備安裝形式；原廠工作點、配對及性能追查保留為工程深化事項。正式報告保留簡短候選狀態，詳細來源、假設及缺項放入計算工作簿。
