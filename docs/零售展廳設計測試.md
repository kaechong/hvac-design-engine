# 零售展廳 HVAC 設計測試（2026-09-07）

本次以使用者提供的 28 頁室內設計圖紙作端到端設計測試。工作範圍僅包括設計資料整理、冷負荷／通風／排風計算，以及供下一個畫圖助手使用的設備需求；不產出施工圖，亦不作設備最終選型。

## 輸入來源及已知限制

- 圖紙：`data/raw/完整設計測試圖紙.pdf`；平面主要依據 P1、P10、P20，並以 P3、P12、P22 的天花／空調符號作交叉核對。
- 圖紙未提供朝向、圍護結構、U 值、玻璃 SHGC、實際樓高、正式人數、營業時段、設備發熱量、機電系統圖及設備性能表。
- 因此 232 m² 的房間面積、3.0 m 樓高、人數、圍護／日射負荷及逐時時表均為測試假設，所有結果狀態均為 `CalculationOnly`，不得作施工或採購依據。

## 固定設計條件

- 室內：23 °C、55 % RH。
- 室外（澳門夏季）：34 °C DB／28 °C WB。
- 新風：10 L/s·人；本測試人數合計 92 人，合計 920 L/s（3,312 m³/h）。
- 衛生間排風：15 ACH；兩個衛生間合計 87.5 L/s（315 m³/h）。
- 冷負荷安全係數：只在各系統原始尖峰冷負荷總和套用一次 1.15。

## 下一步必須取得的資料

1. 建築平面 CAD 或有比例／尺寸標注的建築圖，及各房實際淨高與面積。
2. 立面、朝向、外牆／屋頂／玻璃構造與遮陽資料。
3. 各房用途、人數、照明、插座及專用設備發熱量、營運時段。
4. 指定空調系統、室外機／PAU／風機可選型號、性能曲線與控制要求。
5. 新風及排風的補風路徑、豎井位置與防火分區資料。

取得以上資料後，應重新執行負荷計算，再把已核定的設備需求交給畫圖助手。
